OpenCV Computer Vision Architecture

This system operates on the background subtraction and morphological contour analysis pipeline from your OpenCV vehicle counting script:

1. Preprocessing: BGR → Grayscale → Gaussian Blur (3×3, σ=5)
2. Background Subtractor: MOG2 (History: 500, VarThreshold: 16)
3. Morphology: Dilate (5×5) → Close (5×5 Ellipse, 2 iterations)
4. Contour Analysis: Bounding Rect ≥ min_width × min_height
5. Centroid Crossing: Trigger when Y_line - offset < cy < Y_line + offset

The web frontend allows dynamic real-time adjustment of detection thresholds, line positions, and live event recording with automated CSV/JSON exports.
